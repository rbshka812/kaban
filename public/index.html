Cybershoke Inventory Live

Userscript для cybershoke.net, который показывает цены Steam-инвентарей всех игроков на сервере и общую сумму прямо в UI Cybershoke.

Установка (3 шага)

  1. Установите Tampermonkey для вашего браузера: tampermonkey.net
  2. Установите userscript: 🚀 Установить Cybershoke Inventory Live (Tampermonkey подхватит .user.js автоматически и покажет диалог установки)
  3. Откройте cybershoke.net, залогиньтесь через Steam, кликните на сервер — увидите цифры рядом с никами и панель с общей суммой.

Как это работает

  • Userscript встраивается в страницы cybershoke.net
  • Когда вы открываете сервер, скрипт перехватывает API-ответ Cybershoke (видит SteamID игроков из вашей залогиненной сессии)
  • Отправляет список SteamID на наш backend на Vercel
  • Backend дёргает Steam-инвентари + цены Skinport (~18 тыс. скинов CS2)
  • Userscript рисует цены рядом с никами + общую сумму в правом нижнем углу

Настройка backend URL

По умолчанию userscript обращается к http://localhost:3000 (для локальной разработки). После деплоя на Vercel выполните в консоли cybershoke.net: 

csliSetBackend('https://your-app.vercel.app')

URL запоминается в localStorage, повторно вводить не нужно.
